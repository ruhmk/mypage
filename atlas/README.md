# Atlas Snapper

ローカルだけで動く、複数画像向けのテクスチャアトラス作成ツールです。`index.html` をブラウザで開くだけで使えます。

## 使い方

1. `index.html` をブラウザで開きます。
2. 右側の画像パネルに PNG/JPG/WebP を追加します。
3. 画像をアトラス領域へドラッグアンドドロップします。
4. 配置済み画像を選び、座標、縮小倍率、Padding、Bleed、固定を調整します。
5. 空白部分をドラッグすると、マインドマップのように作業台の視点を動かせます。
6. アトラス外の薄い作業台にも画像を一時退避できます。
7. `PNG出力` と `JSON出力` で、アトラス内に完全に収まっている配置だけを書き出します。

## 主要機能

- 最終テクスチャサイズ: 1024 / 2048 / 4096 / 8192
- 128px スナップ配置
- 作業台パン: 空白をドラッグして視点移動
- 退避スペース: アトラス外に一時配置可能
- 画像差し替え: 配置済み枠に別画像を落とすと枠はそのまま画像だけ変更
- プロジェクト保存/読み込み
- 外部画像参照プロジェクト保存
- Undo / Redo
- 画像ごとの Padding / Bleed
- PNG の透明ピクセル内 RGB 保持
- 透明RGBビュー、Alphaビュー、mipmapプレビュー
- バリデーションパネル
- スロット固定
- 複数選択、整列、分布

## 退避スペース

アトラス外に置いた画像は「退避中」として扱います。プロジェクト保存には残りますが、PNG/JSON 出力には含めません。

書き出し対象に戻したい場合は、画像全体を濃いアトラス領域の内側へドラッグしてください。

## αチャンネルと透明RGB

PNG は可能な限り生の RGBA として読み込み、α=0 ピクセル内の RGB も保持します。Substance Painter などで透明部 RGB を持っている PNG は、その情報をアトラス出力へ持ち越します。

Photoshop などで既に透明部 RGB が消えている PNG は復元できません。JPG/WebP など通常デコードの形式では、透明ピクセル内 RGB の完全保持は保証されません。

## JSON出力

- `x / y / width / height`: padding を含む配置枠
- `contentX / contentY / contentWidth / contentHeight`: 実際の画像領域
- `uv`: 実際の画像領域のUV
- `slotUv`: padding を含む配置枠のUV
- `padding / bleed`: 画像ごとの余白と外周押し出し幅
- `alphaRgbPreserved`: PNG の透明ピクセル内 RGB を保持できている場合は `true`

退避中の配置は JSON 出力から除外されます。配置プロジェクトには保存されるため、作業を再開してからアトラス内へ戻せます。
