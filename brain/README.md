# Mental Cache Prototype

未確定事項を脳から退避し、必要な日まで視界から消すための個人向けプロトタイプです。Todoを細かく管理するのではなく、「今考えなくていいこと」を増やすことを目的にしています。

対応ブラウザは Google Chrome のみです。音声入力とエクスプローラー経由の保存/読み込みはChrome前提で作ります。

## 使い方のイメージ

1. 左カラムの入力欄に、気がかりを整理せずそのまま入れます。
2. 音声メモ欄の「聞き取り開始」で、未整理のまま話した内容を文字起こしします。
3. 必要なら文字起こしをChatGPTに貼って整理し、箇条書きを音声メモ欄に戻します。
4. 音声メモ欄を手動で直してから「分解して追加」で複数の気がかりへ分けます。
5. 1件だけ入れたい場合は、上部の入力欄に書いて「送る」を押します。
6. 追加された内容は簡易AI風ロジックで自動分類されます。
7. 今日見るべきものは中央のインサイト枠に追加されます。
8. 保留、委任、アイデア候補は右カラムの `AI SORT` に蓄積されます。
9. `AI SORT` は家庭、仕事、副業のカテゴリに分かれ、`+ / -` で開閉できます。
10. `AI SORT` のフィルターで、全件、今やる、7日以内、1か月以内、未定保留を切り替えます。
11. カードはドラッグで並び替えたり、別カテゴリへ移動できます。
12. `AI SORT` の項目をクリックすると、右側にインスペクターが開きます。
13. インスペクターの状態、保留優先度、重さ、カテゴリ、再提示日、委任先、メモは変更した時点で反映されます。
14. 各カードの `完了` ボタンを押すと、カードは `完了` カテゴリへ移動し、完了日時が記録されます。
15. `レポート` ボタンを押すと、過去1週間・1か月で完了した件数を確認できます。
16. 中央カラムで脳内占有率、3カテゴリの円グラフ、重さインパクト円グラフ、カテゴリ別負荷バー、削減アドバイスを確認します。
17. アドバイス欄を押すと、`AI SORT` がアドバイス対象のカードだけに絞り込まれます。もう一度押すと全件に戻ります。
18. 中央の `今やる / 保留 / 委任 / アイデア` カードを押すと、`AI SORT` がその状態だけに絞り込まれます。もう一度押すと全件に戻ります。
19. 今日見るものリストのカードを押すと、`AI SORT` 側の該当カードへ移動します。
20. カラム間の細いバーをドラッグすると、各カラム幅を調整できます。
21. 右上の「保存」でエクスプローラーを開き、JSONファイルとして保存できます。
22. 右上の「読込」でエクスプローラーを開き、保存済みJSONを読み込めます。

## 想定する運用

- 入力時に分類しない
- 文章は雑でよい
- ユーザーはタグやフォルダを作らない
- 保留は「覚えておく」のではなく「見えない場所へ退避する」
- 同じ悩みが繰り返し出たら、決断・委任・保留の優先度見直し候補にする

## 現在のプロトタイプ範囲

- ローカルHTMLのみで動作
- 外部ライブラリなし
- 入力内容の簡易分類
- Chrome音声認識による音声メモ
- 音声メモ全文の複数項目分解
- 再提示ボタン
- 脳内占有率ダッシュボード
- 3カテゴリ別の円グラフ、重さ別の円グラフ、負荷バー、削減アドバイス
- 削減アドバイス対象カードのAI SORTフィルター連動
- 状態タグ別の集計カードとAI SORTフィルター連動
- 今日見るものからAI SORTカードへのジャンプ
- カラム幅のドラッグ調整
- AI SORT項目のインスペクター編集
- AI SORTのカテゴリ開閉とドラッグ移動
- 完了カテゴリへの移動
- 過去1週間・1か月の完了レポート
- AI SORTの条件フィルター
- 保留項目の優先度 高 / 中 / 低
- やる内容の重さ 高 / 中 / 低
- 重さを鑑みた削減候補の提案
- インスペクター変更の即時反映
- JSONファイルへの保存と読み込み

## 保存形式

保存ボタンはエクスプローラーの保存ダイアログを開き、`mental-cache-YYYY-MM-DD.json` というJSONファイルを作成します。読み込みボタンもエクスプローラーのファイル選択ダイアログを開きます。

Chromeのファイル選択APIを使う前提です。他ブラウザでの挙動は検証対象外です。

保存される主な項目は以下です。

- 内容
- 状態
- 保留優先度
- 重さ
- 再提示日
- カテゴリ
- 委任先
- メモ
- 完了日時
- 作成日時
- 更新日時
