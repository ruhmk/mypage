# Flow Fragments

日時メモツール「Today Fragments」の見た目とキャンバス操作を流用した、PC向けのローカル・フローチャート思考ツールです。

## 起動

`index.html` をブラウザーで開きます。ローカルHTTPサーバーを使う場合は、このフォルダーで次を実行します。

```powershell
python -m http.server 5177
```

その後 `http://127.0.0.1:5177` を開きます。

## 主な操作

- 「新規ファイル」で現在の全フローを閉じ、カード・線・グループのない空のフローから開始。保存して切替／保存せず切替／キャンセルを選択できます。
- 新規ファイルは「保存」を押すまで外部JSONに保存されません。ブラウザー内の自動保存・次回起動時の復元は続きます。新規作成しても保存済みのJSONや最近のファイル一覧は削除しません。
- 左カラム下部の入力欄からカードを追加（1行目がタイトル、2行目以降が展開メモ）
- カード上で右クリックしたまま別カードへドラッグして接続（線は右端の丸から相手カードの左中央へ描画）。Shift＋右ドラッグで上側の戻りループ、Alt＋右ドラッグで下側の差し戻し、Ctrl＋右ドラッグで自己ループ
- カード右端をドラッグすると横幅、下端をドラッグすると高さを25px単位で変更
- カード詳細の「接続先を選択」からも接続可能（同じ接続がすでにあるときは追加しません）
- 接続線を選択し、条件や説明文を入力。線の種類・色・円弧の高さも変更できます
- カードの `− / ＋` でメモを開閉
- 左サイドバーでフロー、タグ、カードを切替（タグを選ぶと該当カードの一覧を表示）
- 上部両端の矢印で左右カラムを開閉。開閉状態はブラウザー内に保存されます。
- フロー名の横の「☰」からフローの複製・削除
- 「ファイル」メニューから新規ファイル・開く・別名保存・最近のファイルを操作。「保存」は上部に常時表示
- ブラウザー内には自動保存（タブを閉じる・隠す時も即時に書き込み）
- `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` でUndo/Redo（入力欄にフォーカスがある間は、ブラウザー標準の文字の取り消しになります）
- Shift＋クリックでカード・領域を複数選択。まとめて移動でき、`Delete` でまとめて削除できます。複数カードの共通項目はインスペクターで一括編集できます
- カードを領域内へ移動すると子カードになり、領域の移動・色に追従
- グループにマウスを重ねると右上に南京錠が表示され、クリックでロック／解除（インスペクターからも切替可能）
- ロックで固定されるのはグループ本体の位置・サイズのみ。子カードはロック状態に関わらず移動・縦横リサイズ可能。ロック中のグループ上のドラッグは視点移動
- カードまたは領域を選択し、`Ctrl+C` / `Ctrl+V` で複製（領域は子カードと内部接続も含む）。フローをまたいで貼り付けできます
- 「時系列」で月別タイムライン表示へ切替
- 表の見出しをダブルクリックして直接変更（行名は改行可）。表上の＋／−で項目・期間を増減。行は途中にも差し込めます
- 列・行を削除すると、削除した列・行より後ろにあるカード・領域は削除した幅・高さの分だけ前へ詰まります
- 行ラベルをドラッグして項目を並べ替え（ドロップ時に行内のカードも一緒に移動）
- 縦軸は人・部署・役割・案件など任意の分類に対応
- 接続線はカード右側の○から接続先カードの左中央へ描画
- 時系列表示でもカードは25pxグリッドの自由配置で、セルへ強制的に吸着させることはありません。同じ項目・同じ期間内にも複数カードを自由に配置できます
- 時系列の各行は自動で色分けされ、グループ未所属カードは中心位置がある行の色を自動で引き継ぐ（グループ色が優先）
- 月見出し右端と項目行下端をドラッグして、時系列・項目の幅・高さを25px単位で変更。Ctrl＋ドラッグで後続のカード・領域も一緒に移動
- 表の左上をドラッグすると表全体を移動。項目名列の右端をドラッグすると項目名列の幅を変更
- グループ右下をドラッグして自由にリサイズ
- グループ内に入ったカードは自動的に子カードとして所属
- カード詳細から親グループを明示的に選択可能
- カードとグループの位置・サイズはすべて25pxグリッドへスナップ。ドラッグ中から25px刻みで移動・リサイズされます

## 保存とデータ

- データはクラウドへ送信されません。ブラウザー内の自動保存には `localStorage`（`flow-fragments-state-v1`、`flow-fragments-ui-v1`）、最近のファイルのハンドルには IndexedDB（`flow-fragments-recent-files`）を使用します。
- 外部JSONへの保存は「保存」「別名保存」から。対応ブラウザーでは File System Access API で上書き保存し、未対応ブラウザーではダウンロード／アップロードに切り替わります。
- 読み込んだJSONは検証してから反映します。形式が合わないファイルは「対応していないJSONです」と表示し、現在のデータは変わりません。
- ブラウザー内の保存データが壊れていて読めなかった場合は、元の文字列を `flow-fragments-state-v1-recovery` に退避したうえでサンプルから開始します（アプリはこのキーを読みません。必要なときに開発者ツールから取り出せます）。

## 書き出し

- 「PNG」で図全体を100%サイズのPNGに保存
- 「文脈を書き出す」でAIに渡すための Markdown・PNG・JSON を ZIP にまとめて保存。メニューから文脈のコピー、Markdownのみ、PNGのみの書き出しもできます
