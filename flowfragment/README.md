# Flow Fragments

日時メモツール「Today Fragments」の見た目とキャンバス操作を流用した、PC向けのローカル・フローチャート思考ツールです。

## 起動

`index.html` をブラウザーで開きます。ローカルHTTPサーバーを使う場合は、このフォルダーで次を実行します。

```powershell
python -m http.server 5177
```

その後 `http://127.0.0.1:5177` を開きます。

## 主な操作

- 下部入力欄からカードを追加（1行目がタイトル、2行目以降が展開メモ）
- カード上で右クリックしたまま別カードへドラッグして接続（線は右端の丸から描画）
- カード右端をドラッグすると、期間を表す横幅を25px単位で延長・短縮
- カード詳細の「接続開始」からも接続可能
- 接続線を選択し、条件や説明文を入力
- カードの `− / ＋` でメモを開閉
- 左サイドバーでフロー、タグ、カードを切替
- 「整列」で上流を左、下流を右へ全体自動整列
- 「保存」「読込」で全データを1つのJSONとして入出力
- ブラウザー内には自動保存
- `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` でUndo/Redo
- カードを領域内へ移動すると子カードになり、領域の移動・色に追従
- 領域をロックすると、領域と子カードの位置を固定
- カードまたは領域を選択し、`Ctrl+C` / `Ctrl+V` で複製（領域は子カードと内部接続も含む）
- 「時系列」で月別タイムライン表示へ切替
- 「軸設定」で開始月、表示月数、縦軸の項目を自由に設定
- 縦軸は人・部署・役割・案件など任意の分類に対応
- 時系列表示ではカード移動後に最寄りの月・縦軸行へスナップ
- 接続線はカード右側の○から接続先カードの左中央へ描画
- 時系列の横位置は半月単位、縦位置は細かなグリッド単位で配置可能
- 同じ項目・同じ期間内にも複数カードを自由に配置可能
- 縦軸の項目名はラベルをダブルクリックして直接変更
- カード下端をドラッグして縦幅を自由に変更
- 月見出し右端と項目行下端をドラッグして、時系列・項目の幅を変更
- カードは自由配置が基本で、時系列・項目の基準線付近だけ磁気スナップ
- グループ右下をドラッグして自由にリサイズ
- グループ内に入ったカードは自動的に子カードとして所属
- カード詳細から親グループを明示的に選択可能
- カードとグループの位置・サイズはすべて25pxグリッドへスナップ
- ドラッグ中から25px刻みでしか移動・リサイズされないリアルタイムスナップ

データはクラウドへ送信されません。通常保存にはブラウザーの `localStorage` を使用します。
