# Knowledge Map Canvas

ローカルで動く、編集可能なマインドマップツールです。

## 画面の構成

- 左: ファイル（新規・開く・保存）、階層、表示の調整、出力
- 中央: マップ
- 右: インスペクター（選んでいるノードの詳細だけを表示・編集）

## 使い方

1. `MindmapIndex.html` をブラウザで開きます。
2. ノードをクリックして選択すると、右のインスペクターにそのノードの詳細が出ます。
3. ノード内の文字をそのまま編集できます。インスペクターの `タイトル` でも変えられます。
4. 各ノードには `詳細・補足` を書けます。インスペクターで書くか、カード上の詳細をクリックして直接書きます。右クリックの `詳細を書く` でもカード上で書き始められます。
5. 詳細はカードのタイトルの下に、少し小さい文字で全文が表示されます。カードの縦の長さは詳細の量に合わせて伸びます。
6. カード上で詳細を書いているときは、`Enter` で改行、`Esc` か `Ctrl + Enter` で入力を終えます。
7. 詳細のあるカードは、下端の取っ手を上へドラッグすると縦幅を好きな高さまで縮められます。入りきらない詳細は自動で `…` に省略されます（1行も入らないときは小さな `…` だけ出ます）。下へドラッグして全部見える高さまで戻すか、取っ手のダブルクリック、インスペクターの `全部表示に戻す`、右クリックの `縦幅を戻して全部表示` で元に戻ります。縮めたカードの詳細を書いている間は、一時的に全部表示されます。全文はインスペクターに残ります。
8. ノードをドラッグして手動で位置調整できます。親ノードを動かすと子ノードも追従し、スナップ幅に合わせて吸着します。
9. ノード右側の `+`、`×`、`▾/▸` で子ノード追加、削除、開閉できます。
10. インスペクターで種類と関係線タイプを設定できます。
11. マップはMDファイルとして保存・読み込みします（下の「保存と読み込み」）。
12. 別のマップに切り替えるときは、`開く` でそのMDファイルを開きます。
13. `横の距離` と `縦の距離` でノード同士の間隔を調整できます。
14. 開閉や表示の細かさ変更でノードが重なる場合は、自動で近い位置へ逃がします。
15. `自動整列` は内容を残したまま、手動で動かした位置を初期化して自動レイアウトへ戻します。
16. `検索` は見出しと詳細・補足の両方から探します。
17. `PNG保存` で現在表示中のマップ全体を100%解像度のPNGとして保存できます。詳細も、縮めた縦幅のまま描かれます。
18. `3D` で、通常の親子マップ全体を階層0として、別レイヤーをフロアマップ風に表示できます。
19. 3D表示中は階層0をY基準に、下階層ほどY-方向へ固定配置します。
20. 3D表示中は `上` / `下` でアクティブ階層を選べます。3D位置は変えず、選択中の階層がハイライトされます。
21. `下層に追加` で選択ノードのゴースト複製を下レイヤーへ追加できます。レイヤー間は通常の親子線とは違う点線で見えます。
22. `階層決定` で選択中のレイヤーだけを2D表示にできます。`通常2D` で階層0へ戻せます。
23. 3D表示中は背景上で `左ドラッグ` で見まわし、`右ドラッグ` は右で拡大、左で縮小、`中ドラッグ` でPANできます。`Alt` を押しながらでも同じ操作ができます。
24. 中ボタンのホイールでもカーソル位置を中心に拡縮できます。
25. `全体表示` で、2Dでも3Dでもマップ全体を画面に収めます。
26. `最大化` でマップだけをウィンドウ全体に表示し、`戻す` で元に戻せます。
27. `Ctrl + Z` でUndo、`Ctrl + Shift + Z` でRedoできます。
28. 左側の `階層` からレイヤーを切り替えたり、全階層3D表示へ戻れます。
29. ゴーストノードを選ぶと `元へ` で元ノードへジャンプできます。
30. `フォーカス` で選択ノード、その親筋、子孫だけを濃く表示できます。
31. ノードを右クリックすると、追加、下層追加、詳細の編集、縦幅を戻す、種類変更、関係線変更、削除をまとめて操作できます。
32. ドラッグ中に近いノード中心へ揃うと整列ガイドが表示されます。
33. 枝の色は上位トピックごとに自動で割り当たります。

## 保存と読み込み

マップの中身は、PCのMDファイルにだけ保存します（ブラウザ内にマップを溜めておく仕組みはありません）。

- `新規`: 新しいマップを作ります。
- `開く`: MDファイルを開きます。
- `保存`（`Ctrl + S`）: 開いているMDファイルに上書きします。まだファイルがないときは保存先を聞きます。
- `名前を付けて保存`（`Ctrl + Shift + S`）: 別のMDファイルとして保存します。
- 左上の印で、`未保存の変更あり` / `保存済み` が分かります。保存していない変更があると、タブの名前の先頭に `●` が付きます。
- 保存していない変更があるまま `新規` や `開く` を押すと、`保存して続ける` / `保存しないで続ける` / `やめる` を選べます。
- 保存していない変更があるままタブやブラウザを閉じようとすると、ブラウザの確認が出ます。`キャンセル`（このページに留まる）を選ぶと、マップの下に `保存` ボタンつきのお知らせが出るので、その場で保存できます。

ブラウザに残すのは、次の2つだけです。

- 作業中の写し: 保存前にブラウザを閉じてしまっても、次に開いたとき続きから再開できます。そのときは「前回、保存しないまま閉じた変更を復元しました」と出て、`保存` か `保存済みの状態に戻す` を選べます。
- 開いているファイルの場所（中身ではありません）: 開き直したあとも同じファイルへ上書き保存できるようにするためです。ブラウザが書き込みの許可を聞いてくることがあります。

以前の版で `保存` ボタンを使ってブラウザ内に置いていたマップは、左の「ブラウザに残っている以前のマップ」に一覧で出ます。開いて `保存` でMDファイルにしてください。すべてファイルにしたら、`この一覧をブラウザから消す` で消せます（消すまでは残ります）。

ファイルへ直接書き込めないブラウザでは、`保存` はダウンロードとして保存します。

## AIに読み込ませる

左の `出力` で `JSON` か `Markdown` を押し、`コピー` でAIに貼り付けます。どちらにも詳細・補足が入ります。

- JSON: `tree` の各ノードに `text`（見出し）、`detail`（詳細・補足）、`type`（種類）、`children`（子ノード）などが入ります。先頭の `about` に各項目の意味が書いてあるので、AIが文脈として読み取れます。別階層のゴーストは `layer` と `parallelOf`（元ノードのid）で分かります。
- Markdown: 見出しの箇条書きの下に、詳細・補足が `> ` で始まる行として続きます。

```text
# テーマ
> テーマ全体の補足
- トピックA
  > トピックAの詳細
  - 詳細A1
- トピックB
```

## 保存されるMDファイルの中身

`保存` で書き出すMDファイルは、上の読みやすいMarkdownに加えて、先頭にツール用メタデータをコメントとして埋め込みます。
このコメントにノードのid、種類、関係線タイプ、開閉状態、カードの縦幅、階層、手動位置、表示の細かさ、ノード間隔、スナップ幅が保存されます。
詳細・補足は本文の `> ` の行に入ります。通常のMarkdownとして読むこともでき、このツールで開くと状態を復元できます。
以前のファイル（メモを埋め込みにだけ持っていたもの）も、そのメモを詳細・補足として読み込みます。
